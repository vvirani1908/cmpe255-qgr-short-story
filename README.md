# CMPE 255 Short Story Assignment

## Topic

**Quantized Graph Representation Learning for Data Mining and Large Language Models**

This project explains how graph data can be converted into compact discrete codes instead of only continuous embeddings. The topic connects graph representation learning with data-mining tasks such as link prediction, recommendation, clustering, knowledge-graph search, and graph generation.

## What the presentation covers

1. Limitations of ordinary graph embeddings
2. The encode–quantize–decode architecture
3. Vector, residual, scalar, and anchor-based quantization
4. Node-, edge-, and graph-level learning objectives
5. Connecting graph codes with large language models
6. Evaluation metrics for accuracy, compression, robustness, and code usage
7. Ablation studies that test which components actually matter
