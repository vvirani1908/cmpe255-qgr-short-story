# CMPE 255 Short Story Assignment

## Topic

**Quantized Graph Representation Learning for Data Mining and Large Language Models**

This project studies how graph data can be represented with compact discrete codes instead of only continuous embeddings. The topic connects graph representation learning, knowledge-graph mining, link prediction, compression, graph generation, and graph–language-model integration.

## Presentation summary

The presentation explains:

1. Why ordinary graph embeddings become difficult to scale and interpret
2. The encode–quantize–decode architecture
3. Vector, residual, scalar, and anchor-based quantization
4. Node-, edge-, and graph-level training objectives
5. How discrete graph codes can interface with LLMs
6. Metrics for task quality, compression, robustness, and code usage
7. Ablation studies needed to isolate the value of quantization
